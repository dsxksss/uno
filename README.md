《职场大逃杀：KPI突围》卡牌游戏策划方案

一、核心玩法概念

- 游戏类型：职场题材 + 卡牌对战 + 轻度肉鸽
- 胜利条件：率先将自己部门的“打工人卡牌”全部“优化”（裁员）完成KPI
- 对战规模：2-4人竞技（支持单人PVE模式）

二、卡牌体系设计

1. 部门卡组（玩家选择初始阵营）

- 开发部：主打“技术攻坚”、“代码重构”、“深夜加班”
- 业务部：擅长“客户拜访”、“合同谈判”、“业绩冲刺”
- 行政部：拥有“流程优化”、“资源调配”、“会议轰炸”
- 管理部：掌握“战略调整”、“绩效考核”、“组织架构”

2. 核心卡牌类型

- 打工人卡（基础单位）
   - P1-P3：实习生/初级员工（生命值低，易被优化）
   - P4-P6：骨干员工（中等属性，有特殊技能）
   - P7-P9：高级专家/管理者（高生命值，裁员成本高）
- 技能卡（主动释放）
   - 直接优化：“PIP考核”、“末位淘汰”
   - 增益效果：“咖啡激励”、“弹性工作制”
   - 干扰对手：“跨部门会议”、“紧急需求”
   - 保护己方：“居家办公”、“调岗安排”
- 环境卡（全局影响）
   - “经济下行”：所有裁员效果+1
   - “公司融资”：全员获得临时护盾
   - “全员996”：攻击力提升但持续掉血

3. 特殊机制卡

- 小丑牌变体 - “摸鱼卡”
   - 打出后随机触发效果：摸鱼成功（跳过一次裁员）/摸鱼被抓（受到惩罚）
- 肉鸽元素 - “职场奇遇”
   - 每回合可能触发：猎头挖角（失去员工）、突发需求（增加压力）等

三、核心游戏机制

1. 资源系统

- 人力成本：每回合自动获得，用于打出高等级卡牌
- 职场压力：相当于生命值，压力爆表则进入“burnout”状态
- KPI进度：显示裁员完成度

2. 行动阶段

- 准备阶段：抽卡、获得基础资源
- 主阶段：打出卡牌/使用技能
- 优化阶段：执行裁员行动
- 结束阶段：结算持续效果

3. 肉鸽成长系统（单机模式）

- 每局游戏后获得“职场经验”
- 解锁新卡牌、部门皮肤、特殊Boss
- 天赋树：分为“狼性文化”、“人文关怀”等不同路线

四、趣味性设计

1. 梗元素融入

- 卡牌名称：“无效加班”、“甩锅神技”、“对齐颗粒度”
- 特殊效果：“周五发布”（使对手周末加班）、“钉钉轰炸”（连续干扰）

2. 动态事件系统

- 随机事件：“集体离职潮”、“监管新规”、“茶水间八卦”
- 节日彩蛋：春节期间“年终奖发放”（全员恢复压力）

3. 部门特色终结技

- 开发部：“系统重构” - 清空对手所有低级员工
- 业务部：“超级大单” - 直接完成30%KPI
- 行政部：“预算削减” - 封印对手高成本卡牌
- 管理部：“组织调整” - 随机交换双方部分员工

五、美术与UI风格

- 采用夸张的职场漫画风格
- 卡牌原画：打工人各种崩溃又努力的生动表情
- UI设计：模仿办公软件（钉钉/企微风格界面）
- 音效：键盘声、消息提示音、叹息声

六、游戏模式

1. 快速对战：标准1v1，10-15分钟一局
2. 晋升之路：肉鸽单机，挑战不同公司Boss
3. 团队竞技：2v2部门协作战
4. 特殊模式：
   - “大小周”：行动轮次减半的快节奏模式
   - “弹性工作”：可自由安排行动顺序

七、商业化与扩展设想

- 赛季通行证：每赛季推出新部门（如设计部、市场部）
- 卡牌皮肤：不同公司主题（互联网大厂版、外企版等）
- 扩展包：新增“远程办公”、“AI替代”等机制
- 自定义模块：玩家可设计自己公司的卡牌

核心设计理念：用黑色幽默解构职场生态，让玩家在“优化同事”的过程中获得压力释放的快感，同时通过卡牌策略的深度和肉鸽的随机性保证重玩价值。游戏既要有足够的策略深度，又要保持轻松搞笑的氛围，避免真正引起职场焦虑。
